# Stitchnook

Free cross-stitch pattern maker that runs in your browser — **no account, no subscription, no locked features**.
Available in English, French, Spanish and German (follows the system language).

Everything stays on your device: projects are saved in the browser (IndexedDB) and in the backup / project
files you export. The site works offline once installed (PWA).

If it helps you, you can support it on [Ko-fi](https://ko-fi.com/stitchnook).

## Features

- **Projects** — autosave in the browser, project library with folders, full backup / restore, JSON export / import.
- **Fabric** — size in stitches or in cm / inches, common fabrics (Aida 11–18, evenweave) or free count; the finished size is computed live.
- **Threads** — the full DMC stranded cotton catalogue, searchable by number or name, nearest-DMC color picker, a printable symbol per thread.
- **Drawing** — pencil, eraser, fill, eyedropper, line, rectangle, ellipse, selection with copy / cut / paste, mirror, rotate, resize.
- **Image & PDF import** — turn a picture into a chart in DMC colors, or rebuild a chart from a PDF.
- **Motif library** — reusable motifs, organised in folders.
- **Text** — Google Fonts and system fonts rasterised into stitches.
- **Progress** — mark stitched cells, progress per color, color filter.
- **Print / PDF** — paginated chart with coordinates, color or black and white, thread key with estimated lengths.

## Development

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # type check + production bundle in dist/
npm run lint       # oxlint
```

Interface texts live next to the code that shows them, in `*.i18n.ts` files (French is the reference shape,
TypeScript checks the other languages against it). See `src/i18n/index.ts`.

The presentation pages (`public/<lang>/`), `sitemap.xml` and `robots.txt` are generated by
`node scripts/build-landing.mjs`.

### Publishing (GitHub Pages)

```bash
npm run deploy                     # build + lint, then publish the committed master
npm run deploy -- "Release notes"  # same, with a custom message
```

Only committed changes are published: `scripts/publish.sh` copies the tree of `master` into a separate,
anonymous history (branch `public`) and pushes it to the public repository, where GitHub Actions deploys
the site.

### Desktop build (personal use)

```bash
npm run electron   # run the desktop shell locally
npm run dist:mac   # unsigned macOS app in release/
npm run dist:win   # unsigned Windows portable .exe in release/
```
